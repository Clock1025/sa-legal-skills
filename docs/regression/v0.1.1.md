## Zero-install 實測

### 測試目的與方式

確認使用者不需 clone、安裝或事先下載整個 repository，只要在具備 GitHub 存取能力的 AI Agent 中提供 repository URL 與 Skill 路徑，即可正確讀取並執行 Skill。

- 使用全新對話，不提供既有專案背景。
- 提供 repository：https://github.com/Clock1025/sa-legal-skills。
- 指定 `skills/regulation-review/SKILL.md`。
- 要求 Agent 實際讀取 Skill；若無法讀取，應明確告知，不得宣稱已讀取。

### Case 1：Skill 載入 — PASS

Agent 能正確識別：

- `regulation-review`。
- 描述性問題與合規判斷的區別。
- 四種合規結果：符合、不符合、有合規疑義、資料不足。
- 法規版本查核要求。
- 不依記憶重建法規。
- 不自行補完未決制度政策。

### Case 2：案件法源載入 — PASS

提供《新北市立板橋高級中學學生聯合自治會組織章程》。Agent 將使用者提供的章程作為案件法源，沒有以模型記憶取代正式文本。

### Case 3：描述性法規問題 — PASS

問題為「誰有公布法律的權限？」及「是否規定公布完成期限？」。實測回報 Agent 正確判斷：

- 公布法律主體為學生會會長。
- 十日是學生議會移交法律案的期限，不是會長完成公布的期限。
- 章程沒有明定公布完成期限。
- 描述性問題沒有強制套用「符合／不符合」。

### Case 4：合規判斷 — PASS

假設學生議會議長在沒有會長參與的情況下，自行公告議會通過的法律並宣稱已生效。

Agent 分別分析公布權限、必要程序，以及公告與法律生效。實測回報其正確判斷：

- 議長自行公布不符合公布權限規定。
- 未經會長公布及相關副署程序，不符合已明定程序。
- 公告不能直接推導法律已生效。
- 章程欠缺一般性的法律生效規則，因此沒有自行補造生效制度。

### 結果與限制

Zero-install 路徑已成功完成：

```text
GitHub repository → 指定 SKILL.md → 實際讀取 Skill
→ 提供案件法源 → 描述性法規分析 → 合規分析
```

- 本次實測只涵蓋一個具備 GitHub 存取能力的 Agent 環境，不代表所有 AI 都能直接讀取 GitHub。
- README 已保留無法讀取 GitHub 時直接提供 `SKILL.md` 的 fallback。
- 未另外以工具驗證 PDF 每頁解析完整性；不能把「Agent 表示已讀取」視為 PDF 完整性驗證。
- 上述實測未涵蓋 ZIP cold-start；本次另執行下列封裝與入門文件 smoke test。
