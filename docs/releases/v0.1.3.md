本版依實際修法案件及跨模型測試，改善多法規提案、條文移列、修正對照表，以及 Agent Skill 切換規則。

重點更新：
- 多部法規修正須維持**每部法規各自成案**；同批送件或整合工作檔，不代表合成同一件正式提案。
- 跨法規移列至目標法規的新條文，以目標法規的整條新增方式處理；現行條文欄填「（本條新增）」，來源及移列關係保留供追蹤。
- 調整 Word 對照表：未變動文字與結構性空白不得誤加底線；新增條文提示文字不加底線，且在無正式範本要求時採左對齊。
- 強化 **Skill 切換前完整讀取**的規則；不能以「先做」、材料齊備或前階段完成取代讀取。README 補充使用者責任、平台差異及模型相容性資訊。
- 增補回歸測試和模型／平台指南；測試結果按靜態檢查、真實模型行為及獨立驗收分開記錄。

已知但不阻擋發布的限制：
- **R03 的 Skill 切換規則仍有模型差異**：當時 GPT-5.6 Sol／High 測試 FAIL，Claude Sonnet 5.5／Medium 測試 PASS；不能推論所有模型均會遵守。
- **R02 整輪 PARTIAL**：跨法規移列處理實質通過，但無法確認 Skill 完整讀取證據。
- **ChatGPT DOCX PARTIAL**：曾將未變動的「日前」一併畫底線；部分文字排版、字型及跨頁視覺結果未完成獨立複核。
- **Gemini 當次環境的 DOCX 不支援／未驗證**：不推論該平台永久無法產生 DOCX。其他未完成測試的模型不提供比較結論。
