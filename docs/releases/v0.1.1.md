本版改善 Agent Skills 的免安裝使用方式、發布封裝與正式中文法制文字規則，讓新使用者更容易開始使用。

重點更新：
- 支援具備 GitHub 存取能力的 Agent 直接讀取 Repository 和指定 `SKILL.md`，不必先 clone 或安裝；無法連線時可由使用者手動提供 Skill。
- 新增 `START-HERE.md`，作為下載 ZIP 後的獨立入門入口。
- `amendment-drafting` 補充全形中文標點與原文保真規則；URL、識別碼、檔名等必要技術內容保留例外。
- 新增 `scripts/package-release.sh`，以固定五檔白名單製作 `sa-legal-skills.zip`，檢查必要來源檔案並提高封裝可重建性。
- 正式採用 Mozilla Public License 2.0（MPL-2.0），並完成零安裝流程、部分法規審查情境及封裝的煙霧測試。

已知限制：
- 直接讀取 Repository 的方式取決於 Agent 是否具備 GitHub 存取能力；不支援時須改由使用者提供檔案。
- 已完成的測試不代表跨模型全面驗收，正式法規來源及最終產物仍需人工核對。
