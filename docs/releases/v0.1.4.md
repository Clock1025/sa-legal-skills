# sa-legal-skills v0.1.4

## 版本定位與來源

v0.1.4 是 sa-legal-skills 的正式版本，將已驗收的 develop 內容經發布 PR #26 整合至 main，保留 main 原有文件修正及歷史。正式來源 Commit：

`6aa5c775d8ea011ea4b2380ef467591a6966070a`

發布設定為 Stable（Pre-release=false）及 Latest=true。正式版本仍有下列已知限制；正式發布不代表所有模型、平台或真實法律案件均已驗收通過。既有 v0.1.3 與 v0.1.4-rc.1 Tag 不因本版發布而改動。

## 主要更新

- **政策決策狀態與來源追溯：** 區分總體議題與原子決策，保留 I／D／SRC 識別碼、狀態、適用範圍及可核對確認依據。未確認方案與 DIRECTION 不得擅自升格為 CONFIRMED；新增來源不自動擴大既有決策範圍。
- **Skill 讀取與切換：** 延續 START-HERE 唯一 canonical prompt 與完整讀取 gate；切換 Skill 時須先完整讀取新 Skill。無法取得來源或版本時如實揭露，不憑模型自述宣稱已完成讀取。
- **模糊同意與不完整文字：** 多個方案仍有歧義時先釐清使用者指涉；正常、明確且範圍唯一的簡短確認仍可成立。不完整條文不得自行補出任免機關、權限或其他法律效果。
- **Skill Feedback Package：** 統一回報可取得的對話、模型與 Skill 版本來源、附件及輸出清單，區分 COMPLETE／PARTIAL／UNVERIFIED；無 ZIP 工具時提供文字回退，不虛構缺漏資料。
- **DOCX 文件品質：** 補強長篇三欄修正對照表的分頁、標題列重複、原文與欄位對應、中文段落及底線規範。不得為排版刪減條文；正式法規文件及對照表預設 A4 直式，使用者明確指定或權威正式範本另有要求時例外。
- **驗收工具與使用指南：** 提供真人模型驗收矩陣、證據完整性檢查、半自動 TXT 匯入摘要及實際 DOCX 品質檢查工具，並整理各平台已知限制與替代操作方法。工具不自動呼叫付費模型、不替代法律判斷或人工看頁。

## 已知限制與使用責任

- CASE-05 的釐清提問仍可能不足；不完整來源與未確認政策須由使用者補明，AI 不得自行定案。
- C05 的預設直式修補尚待模型複驗；仍須核對實際產物的文字、三欄對應、底線、縮排、字型及分頁。
- Microsoft Word 跨平台相容性尚未驗證。LibreOffice 或其他環境的檢查不能直接等同 Word 驗收。
- 完整真實修法案件的端到端流程尚未完成試用；其他模型及平台不因本版正式發布而視為已通過。
- 三個 Skill 是 AI 輔助工作規則，不取代正式法律程序、法規有效性查核或有權機關決策。使用者須核對法規來源、版本、政策確認、提案內容及適用程序；法律效果與最終文件應由有權者確認。虛構回歸材料不是真實有效法規。
