# v0.1.4 — 決策管理與修法文件品質改善

## 版本定位

`v0.1.4` 為正式穩定版（Stable Release），主要改善學生自治法規工作的政策決策確認、來源追蹤、Agent Skill 工作流程及 DOCX 修法文件品質。**穩定版不代表所有模型、所有平台或真實法律案件均已完成驗收，也不保證法律內容正確。**

本版固定來源 Commit：`6aa5c775d8ea011ea4b2380ef467591a6966070a`。

## 主要更新

- **決策狀態與來源追溯**：區分議題與原子政策決策，維護 I／D／SRC 識別碼、適用範圍、確認依據及歷史映射；對含糊同意與偏好傾向，避免誤升為已確認政策。
- **Skill 閱讀與階段切換**：加強各階段完整讀取 Skill 的前置條件、固定版本與來源核對，以及不完整法律文字的釐清要求；不得自行補寫未確認的任免權限等制度內容。
- **Skill Feedback Package**：統一模型與來源資訊、可取得對話、附件及證據完整性回報；無法產生 ZIP 時提供誠實的文字回退，不捏造不存在的原始紀錄。
- **DOCX 修法文件品質**：強化長篇三欄對照表的跨頁、重複標題列、原文保真、中文法規段落及原生差異底線規範；正式法規文件與對照表預設採 **A4 直式**，除非使用者明確要求或權威正式範本另有規定。
- **開發與驗收輔助**：補充真人模型驗收矩陣、證據紀錄、風險分類，以及離線回報／DOCX 品質檢查工具，區分模型行為、靜態檢查、真實文件和視覺驗收。

## 已知限制

- **法律文字釐清**：P0-CASE-05 的主動追問仍有部分限制；法律條文缺漏或政策未確認時，必須由使用者釐清，不可由 AI 擅自決定。
- **排版相容性**：尚未於 Microsoft Word 桌面版驗證所有文件，亦不保證不同辦公軟體、作業系統與字型下的分頁一致。DOCX 原文、底線、跨頁、縮排及字型應由使用者檢查最終檔案。
- **實務流程**：尚未完成完整真實修法案件的端到端試用。
- **模型依賴**：本專案為 prompt-only Agent Skills，Skill 讀取、政策確認與程序邊界是規範要求，沒有獨立 runtime 強制保證；不同模型／平台的 GitHub 存取、附件工具及規則遵循可能不同。
- **驗收範圍**：未宣稱完整真人模型矩陣、跨平台或所有 P0 案例已通過；模型自評不能替代獨立證據。

## 下載與使用

發布附件：

- `sa-legal-skills.zip`：只包含 `START-HERE.md`、`LICENSE` 以及三份核心 Skill：`regulation-review`、`large-scale-reform`、`amendment-drafting` 的 `SKILL.md`。
- `SHA256SUMS.txt`：ZIP 的 SHA-256 校驗值。

下載後將兩個附件放在同一目錄執行 `sha256sum --check SHA256SUMS.txt`，核對通過後先閱讀 `START-HERE.md`，並於實際任務中完整取得對應 Skill 的內容。

使用者仍須核對正式法規來源、版本、政策決定及最終文件。AI 輸出不構成正式法律服務，也不能代替有權機關進行提案、通過、公布、生效、任免或其他正式程序。
