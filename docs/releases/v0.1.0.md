`sa-legal-skills` 的第一個正式版本，建立學生自治法規審查、制度改革及修法起草的三個核心 Agent Skills，並開始使用真實案例進行回歸測試。

重點更新：
- **regulation-review**：區分現行法規描述與合規判斷，分別核對權限、程序、時間及法律效果，不以慣例自行補足權限。
- **large-scale-reform**：分離現行架構、待處理議題及決策紀錄；區分已確認、傾向、未決等狀態，不讓 AI 自行選定政策。
- **amendment-drafting**：依已確認的政策起草法規修正材料，追蹤連動條文，固定修正條文對照表欄序，並規範新增、刪除及差異文字底線。
- 支援在執行環境允許時產生含 Word 原生文字、表格及底線的可編輯 DOCX，並提供正式中文字型使用指引；Repository 不附字型檔。
- 首輪測試涵蓋真實學生自治章程、制度改革決策與修法起草情境，以及 DOCX 格式。

使用範圍與限制：
- 本版提供可重用的 Agent Skills，**不包含**後端、公文系統、MCP 服務或自動產生法律效果的系統。
- 法規政策與正式提案、公布、任免等法律程序仍須由有權機關或使用者依法完成；AI 不得代為作成決定。
- 首輪測試只代表當時的測試情境，不保證所有模型、文件或真實案件均能得到相同結果。

本版原始發布時未附 ZIP 附件；請依 Repository 內對應版本檢視來源檔案。
