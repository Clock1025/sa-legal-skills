## 版本定位

本版是 Google Docs 母版與雙文件流程的封閉 Alpha 試用候選，預計邀請 2～3 位同學協助回報問題。只有實際發布並標記 Pre-release 後才算已發布；本文件與準備 PR 不代表已建立 Tag／Release。這不是 Stable，不標為 Latest；既有 v0.1.x 正式版本保持不動。

## 主要功能

- Google Docs 優先；DOCX 保留為使用者明確選擇的獨立模式，失敗時不自動 fallback。
- 當次授權母版原生複製、核對副本身分；逐條填入原生三欄表格、擴列、精確差異底線與寫後讀回。母版唯讀，不公開私人連結或內容。
- 每次依最新 revision 作原子條件更新，保留人工修改，版本衝突或未知結果停止，不重建全文或建立替代文件。
- 納入 A4 直式、指定標楷體 DFKai-SB、提案正文 14 pt、表格 12 pt／等寬三欄、原生條項款目縮排、說明首行兩字與選擇性 keepLinesTogether。新生成中文呈現與虛構編號採全形；正式來源及必要技術識別碼不正規化。
- 封閉試用入口固定 Skill commit `c07803e57d70ead05d9b5bdc5fdbf86e05ad1fb2`，與 PR #33 合併時三份 Skill 相同；使用 START-HERE 唯一提示詞及 Google Docs 新手操作卡，避免誤用 main／舊版正式附件。

## 驗證與人工驗收範圍

來源以實際發布 Tag 指向的完整 commit 及 SHA256SUMS.txt 為準，不能只憑分支名稱判定。發布準備會對選定的已整合 develop-0.2 commit 重跑 Validator、全部 unittest、固定五檔 ZIP 的來源位元組／CRC／解壓及重建一致性檢查，並產生 SHA-256。PR #33 的既有 121 項測試已通過；發布流程新增的來源防呆測試另計，實際結果以當次 CI 為準。

[PR #33 討論](https://github.com/Clock1025/sa-legal-skills/pull/33)及 repository 驗收指南已有分項外部回報：G01／G03 原生複製填表與精確底線、G02 真人修改保留、G05 過期 revision 拒絕；G04 同階段 checkpoint 續寫、款目／新列縮排與精確底線、G06 短篇視覺及原生說明縮排／全形虛構編號均有已測範圍的通過紀錄。保留 G03 換行底線、G04 新列縮排及 G06 手動空白／半形編號的首次失敗與修正歷史，不記為初次直接 PASS。

這些人工／API 紀錄限其副本、平台、版本與檢查範圍，不是 Codex 此次重新操作 Google Docs，也不是跨模型通用性證明。靜態測試通過不等於實際 Google Docs API 全流程通過。

## 已知風險及未測事項

- 真正跨對話／模型程序中斷後恢復、多人同時競爭、最新 Skill 在不同平台端到端遵循，尚未完整驗證。
- 長篇所有頁面、Android／iPad 等未檢裝置字型與分頁仍為 NOT TESTED／PARTIAL；API 字型名稱不代表實際顯示無替代。
- 模型須實際具備原生複製、讀取、局部編輯與拒絕過期寫入能力；不支援時停止回報，不代表此工具替平台補齊功能。
- 完整發布流程的真實建立 Tag、附件上傳／下載與 Pre-release 切換，在準備階段為 NOT LIVE-TESTED。

## 下載與試用

預計附件為 `sa-legal-skills.zip` 與 `SHA256SUMS.txt`；下載後可用 `sha256sum --check SHA256SUMS.txt` 核對。ZIP 固定只有 START-HERE.md、LICENSE 及三份核心 SKILL.md，詳細指南不在 ZIP。只有實際附件存在時才可下載，不把準備產物稱作已發布。

同學請先讀 START-HERE，使用有權使用的母版與虛構／公開舊案，在隔離副本操作。人工核對原文、政策、底線與版面；問題回報附平台／模型、版本、操作步驟與預期／實際結果，遮蔽私人文件、個資及憑證。試用產物不具有正式提案或公布效力；本專案維持 prompt-only Skills，不是文件編輯後端。
