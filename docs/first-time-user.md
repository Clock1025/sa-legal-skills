# 第一次使用：從想解決的問題開始

不會寫法規也可以開始。先用自己的話說明「現在遇到什麼問題」或「希望事情以後怎麼運作」，讓 AI 協助整理；制度選擇仍由你決定。

在你使用的 AI 開一個新對話，使用 START-HERE 中唯一的可複製提示詞開始，再用自己的話說明問題。介面操作可看 [ChatGPT](platforms/chatgpt.md)、[Claude](platforms/claude.md)、[Gemini](platforms/gemini.md)或[其他 Agent](platforms/generic-agent.md)。

## 開始使用提示詞

請使用 START-HERE.md 中唯一的[可複製提示詞](../START-HERE.md#可複製提示詞)作為新手引導入口。該提示詞包含 repository URL、Skill 選擇優先序、讀取前門檻及提問方式；本頁補充使用流程與案件準備方式，不另維護一份完整提示詞。

判斷 Skill 時，以使用者目前要做的事為準：目前要檢查現行規定或制度，先用 `regulation-review`；已進入整體改革規劃、跨制度協調或大量待決事項追蹤，才用 `large-scale-reform`；方向已定並要準備正式修正文件，再用 `amendment-drafting`。

## 接著提供什麼？

例如先說「我想弄清楚某人能不能代理會長」或「我已決定要增訂一個程序，但不知道怎麼寫」。AI 需要查規定時，再提供正式現行章程、法規或規章，以及版本／生效資訊和必要事實；引用到其他法規時，也盡量一併提供。可以上傳 PDF／DOCX 或貼入法規文字，實際解析能力依平台而定。

若不能讀 GitHub，打開需要的 `SKILL.md`，完整複製全文貼入，或上傳下載檔即可。不需要把三份 Skill 全部提供，也不必安裝或使用 Codespaces。完整讀取同一份 Skill 後，這些提供方式都能使用其中規則。

想要 Word 文件時，可說「制度方向確認後，請依 amendment-drafting 提供可編輯 DOCX；若環境不能產生檔案，請明確告知並提供完整文件內容」。不同模型的長文件處理、規則遵循與檔案輸出能力可能不同，取得結果後仍要核對法規來源與版面。
