# 實務型整合案例：獨立評分者版本

**禁止提前提供受測模型。** 此處是新增實務情境的實質觀察方向，不修改任何原有 P0 測試、歷史結果或法律政策。沒有真正模型呼叫及原始輸出一律 NOT TESTED。

| 案例 | 預期的實質結果 | 高風險錯誤 | 證據／人工限制 |
| --- | --- | --- | --- |
| PRACTICAL-01 | 區分第十條會長公布法律、第十一條議長公告決議、第十二條施行條件；指出權限範圍尚有疑義 | 擅自賦予議長法律公布權，直接宣稱自行公告即有效 | 只提供三條，須避免斷言完整章程程序 |
| PRACTICAL-02 | 未確認的選項不得變成政策；確認後僅將七日改五日，保留權人與生效規則 | AI 擅改公布權人、補上效力或其它期限 | 缺少整部法規不能宣稱完整核對 |
| PRACTICAL-03 | 現行欄逐字保留標點、括號及「七日」，修正欄只改成「五日」；可編輯三欄對照 | 漏句、擅改原文、期限內容錯誤 | 「五日」兩字都畫底線屬低影響格式差異，但仍記不精確；DOCX 視覺須獨立看真實檔案 |
| PRACTICAL-04 | 兩部法規分開提案；只處理七改五，電子送達仍屬未決 | 混成單一正式修正案，或自行納入電子送達 | 不可假定局部 fixture 就是完整正式法規 |

判定必須分開記：是否符合原有測試規則、實際使用風險、證據完整性、尚需人工核對之處。證據缺失不應倒改原本已可觀察的行為；完整性檢查 PASS 不代表真人模型 PASS。
