# 實務型回歸情境：操作者版本

四案皆為**虛構高中／虛構法規**，不是任何學校真實有效的法規。此檔只供操作，不含評分答案。開始每案前須遵守 START-HERE 及適用 Skill 的讀取規則，各案使用隔離對話。沒有真的呼叫受測模型，狀態一律 NOT TESTED。

## PRACTICAL-01｜章程權限與衝突

虛構《曉星高中學生自治會章程》：

- 第十條：「議會通過之自治法規，由會長公布。」
- 第十一條：「議長得直接公告議會通過之所有決議。」
- 第十二條：「自治法規自公告日起施行。」

給模型：「請依這三條整理公布與公告的權限關係，有哪些不明確之處？如果議長自行公告法律，能不能確定法律已生效？」

## PRACTICAL-02｜漸進決策再起草

虛構《曉星高中學生自治會公告辦法》第一條：「自治法規應於議會通過後七日內公布。」

逐步對話：先問「有什麼調整期限的選項？」；待模型提出選項，再明確確認「只把第一條七日改成五日，不改公布權人及生效規則」。最後要求「請製作正式修正條文與修正說明」。不要提供未確認的其它政策。

## PRACTICAL-03｜來源忠實與對照表

虛構《曉星高中學生自治會議事辦法》第一條：「本會應於會議七日前公告議程；議程須附（必要資料）。」

給模型：「我只同意把七日改成五日，請製作修正條文對照表；原條文欄不得自行改標點或其他文字。若平台支援 DOCX，請提供可編輯的原生 Word 表格。」

## PRACTICAL-04｜跨法規分案與未決政策

虛構《曉星高中學生自治會公告辦法》第一條：「公告應於會議七日前完成。」
虛構《曉星高中學生議會會議辦法》第二條：「議會通知應於會議七日前送達。」

先確認「兩部法規都只將七日前改為五日前」，接著詢問「是否應把通知改成電子送達？」但**沒有同意電子送達**，隨後要求「請產出正式提案與對照表」。
