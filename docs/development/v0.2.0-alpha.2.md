# v0.2.0-alpha.2：Google Docs 母版工作流程

對應 [Issue #32](https://github.com/Clock1025/sa-legal-skills/issues/32)。2026-10-16 從最新 `develop-0.2` 的 `1ed6e4e08a751c8e2c62990f7475f45aa6e348f1`（已整合 PR #31）建立 `feature/v0.2-google-docs-template`。PR 目標為 `develop-0.2` 且應為 **Draft**；main／develop 不變，不建立 Tag／Release。

## 實作範圍

- 三份核心 Skill 內嵌相同母版最低規範，五檔 ZIP 可獨立使用：執行時指定授權母版、確認複製與安全編輯能力、原母版唯讀、複製後核對副本／tab／revision、中斷後沿用工作副本。缺母版詢問；無能力／權限、失敗或不明時停止，不臆造或建立替代文件，不自動 DOCX。
- amendment-drafting 增加完整提案製作規範：佔位與來源映射、逐條原生填入、超過兩條原生擴列、精確新增／刪除／替換底線、純改號、長文項款目、格式讀回、checkpoint 續寫及交付完整性檢查。既有法律來源、政策確認、原文保真與 DOCX 獨立模式不變。
- 凍結 Google Docs 母版規格：指定 DFKai-SB（標楷體）、A4 直式、第一頁標題 24 pt、提案欄 14 pt、另起頁的對照表標題 20 pt、表頭／內文 12 pt、三欄各 139.5 pt。這是本母版設定，不新增 DOCX 固定字級，也不代表跨裝置實際字型已驗證。
- 所有副本文字／結構／格式修改都要求新 revision 原子條件與讀回；不把 targetRevisionId 當拒絕衝突機制、不盲目重試／覆蓋、不丟失人工變更。用實際 tab／UTF-16 索引及更新後結構重新定位。
- 同步入口文件與 [操作指南](../google-docs-workflow.md)，新增 [六組虛構人工驗收案例](../acceptance/google-docs-template.md)。不公開任何私人母版 URL、ID、內容或憑證。

本批維持 prompt-only，沒有增加 Google Docs 後端、OAuth／API Key 系統或第四個 Skill；沒有內附／安裝私人母版，也沒有宣稱工具呼叫已成功自動化。

## 已執行的驗證

從 repository 根目錄執行（Bash、Git、Python 3 標準庫）：

```bash
python3 scripts/validate.py
python3 -m unittest discover -s tests -v
git diff --check
```

- 封裝驗證 PASS：固定五檔、來源內容、CRC、解壓縮及兩次獨立封裝 SHA-256 一致。
- 121 項 unittest 全部通過：既有 119 項加 2 項母版靜態契約檢查。既有 ZIP 檢查加強為完整 Skill 位元組一致，涵蓋母版最低規範及 amendment-drafting 詳細規則；不需把 docs 加進 ZIP。
- 差異空白檢查 PASS；CI workflow 無需新增工具或修改，開啟至 develop-0.2 的 PR 後使用既有驗證流程。此處是本機執行結果，不是 GitHub Actions 遠端通過宣告。

靜態測試只檢查規範／封裝契約，不會呼叫 Google Docs、執行模型或驗證實際平台的複製／索引／樣式／衝突行為。

## 未驗證及後續人工驗收

`GOOGLE DOCS LIVE OPERATIONS: NOT TESTED`；`VISUAL QA: NOT TESTED`。

本環境沒有 Google Docs 建立／複製／讀取／編輯工具，也沒有取得私人母版。未執行任何文件操作；以下六組案例均待在有原生工具的平台，以使用者當次提供並授權的母版及虛構副本驗收：

1. 複製身分核對與「七」→「五」精確底線；保留初次格式過寬缺陷及校正後讀回紀錄。
2. 新增「日期、」、保留無關人工修改及純改號。
3. 三條原生擴列，含整條新增／刪除與標記不加底線。
4. 長文項款目真實分頁、逐欄保真及中斷續寫不重複。
5. 實際過期 revision 拒絕寫入，確認人工內容無損且不自動產生替代文件。
6. 實際副本的逐頁人工視覺、字型與格式驗收；Android／iPad、多平台字型及真實多人並行未測時各自標 NOT TESTED。

母版原型的既有使用者驗收只作規格來源，不能轉記為這批 Skill、模型或產物的通過證據。Google Docs 長表格分頁控制須依真實工具確認；無法控制／讀回的屬性須揭露限制。DOCX 既有結構回歸包含在單元測試中，不代表本批進行 Word 渲染／視覺驗收。
